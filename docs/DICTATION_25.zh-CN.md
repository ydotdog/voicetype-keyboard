# VoiceType 1.0.0 (25) — 语言与个人词库

## 本次改动

- 监听 Live Activity 被移除或结束，立即释放后台麦克风。待转写片段保留到 History，用户可重试；旧会话事件不能关闭新会话。
- 灵动岛展开视图和锁屏卡片增加 **Turn off mic** 按钮。iOS 横向滑动灵动岛可能只是收起显示；该手势没有公开通知，不能承诺收起就关闭麦克风。真正移除 Live Activity 时才会触发关闭联动。
- Settings → **Languages & vocabulary** 可选择最多三种常用语言。中文明确区分简体、繁体；不选择时自动识别。单语言作为模型语言参数，多语言作为提示，不把转写变成翻译。
- 中文标点按句规范化，按用户意图转换简繁体，并保护英文句子、网址、邮箱、小数、文件名和代码。中日混合时保留日文句子。
- 个人词库最多 200 条，每次录音发送最近 50 条、总长度不超过 1500 字符的提示。支持新增、删除、清空。
- History → **Edit & teach** 可修改转写，自动建议纠正的人名、地名或词语，保存前可核对并修改。可以关闭学习；不读取其他 App 中用户键入的文字，不从未经用户确认的 AI 输出自动学习。
- 词库按账号保存在本机。删除账号会清除本机对应词库。录音重试使用原始语言和词库快照，保持请求幂等与计费一致。

## 代码检查

本轮由开发代理完成自查，没有另起独立评审代理。

检查范围包括 Live Activity 的事件归属与异步更新顺序、录音保存/取消、失败重试的幂等键、账号隔离与删除、提示词大小限制、旧客户端兼容、键盘插入隔离及新增页面的可访问性。

自查中修复：中文规范化误改无空格相邻文件名/域名的风险；中文设置对混合日文句子的误转换；设备 3 倍像素取整导致原有波形测试误报。转写供应商错误日志不记录响应正文，以避免词库或录音内容出现在日志中。

## 验证

- iOS 全量 112 项通过；另补充“录音期间通过 Live Activity Intent 关闭并保留片段”的测试，相关 10 项通过。合计 113 个不同测试。
- 浅色/深色、320 点窄屏设置页与纠错页已渲染并检查。
- 后端的 Linux 发布镜像使用隔离 SQLite、禁网、模拟供应商运行测试；本机同时执行打包和共享状态检查。最终计数见部署记录。
- 使用人工合成语音实际调用当前 `gpt-4o-mini-transcribe`：短句“你好”；“明天和龚玥在衢州见面，下午三点半。”的简体/繁体；英文 Siobhan / Schenectady。四项接口均正常完成，短句、简繁体、标点、英文词汇符合预期。中文同音人名在重复测试中仍有波动：同语言提示的一组连续三次正确，但最后一轮简体姓名输出了“工月”，繁体输出“龔玥”正确（该轮精确词汇命中 3/4）。这是当前轻量转写模型的质量限制；词库是识别提示，不是强制替换，仍需用户用自己的常用词实测。
- Release 归档及严格签名检查通过；App、键盘和 Live Activity 扩展均为 1.0.0 (25)，不包含测试包。

模拟器和合成语音不证明真机的系统手势或实际收音效果。安装 TestFlight 后重点验证：锁屏移除卡片后橙色麦克风指示消失；展开灵动岛的关闭按钮能停止录音；录音中关闭后可从 History 重试；中文短句、简繁体和自己的常用人名；蓝牙与后台长时录音。
