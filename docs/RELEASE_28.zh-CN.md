# VoiceType 1.0.0（28）发布准备

日期：2026-09-29。正式 App Review 尚未重新提交，仍保留手动发布。

## 本轮修复

- 首次云端转写明确告知音频、语言、词汇提示送往 VoiceType 和 OpenAI，按账户保存同意状态。撤回后停止麦克风，阻止新录音上传和 History 重试；等待系统权限期间也再次检查同意。
- 登录页与设置页提供隐私、支持入口；线上隐私政策同步更新到多条失败录音和撤回授权的实际行为。
- 保留既有键盘点击跳转：麦克风未开启时，点击键盘麦克风直接打开主 App 并自动开启录音，沿用已保存的 session 长度（首次默认 5 分钟），用户手动返回原 App。首次云端同意后自动继续该次明确操作。新增离线字母、数字、空格、标点和大小写切换。
- 上线仅所有者登录的独立模型管理网页，支持密钥更换、模型选择、真实连接测试、加密保存、并发保护和历史恢复。当前只支持已披露的 OpenAI 官方服务。
- 已更新 Apple 新增社交媒体年龄问题、商店介绍和审核操作说明。
