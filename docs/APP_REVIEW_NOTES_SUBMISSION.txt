BACKGROUND DICTATION — GUIDELINE 2.5.4

VoiceType uses background audio to record speech through its containing app while the user dictates from the VoiceType keyboard in another foreground app. The keyboard cannot access the microphone directly. Tapping its outlined microphone opens VoiceType and starts the microphone session. The user manually returns to the original app. Home > Turn on keyboard mic is also available.

TEST ON IPHONE OR IPAD

1. Launch VoiceType and use Sign in with Apple. An Apple Account signed in on the device is required. Check the Credit tab for enough credit for a short transcription.
2. In device Settings > General > Keyboard > Keyboards > Add New Keyboard, add VoiceType. Open its entry and enable Allow Full Access.
3. In an editable Apple Note, select VoiceType using the globe/input-mode control and tap its outlined microphone. VoiceType opens and enables keyboard mic automatically. Allow the system microphone prompt if shown; activation continues after permission is granted. Home displays Ready for the keyboard.
4. Navigate to the Home Screen, then return manually to the same Apple Note and VoiceType keyboard. Notes remains in the foreground while VoiceType records in the background.
5. Tap the keyboard microphone, speak a short sentence, then tap the waveform to finish. Keep the same text field open until transcription finishes and text is inserted.
6. Return to VoiceType. The transcript is also available in History. Tap Turn off keyboard mic on Home. If a clip is active, this finishes and transcribes that clip before ending the session. Home then displays Microphone off.

PERSISTENT AUDIO AND USER CONTROL

The user explicitly turns on keyboard mic. Its audio session stays active between clips for the selected duration: 5 min (default), 12 hr, or Forever. The saved duration is reused when activation comes from the keyboard. Starting and finishing clips does not reset the session timer. Forever means no app timer; system interruptions can still end the session. Individual clips have a 10-minute limit.

Temporary idle audio is rotated and discarded locally. Only recorded clips are submitted for transcription; the full microphone session is not continuously uploaded. If a session ends, tap the outlined keyboard microphone to open VoiceType and start another. Secure fields and apps that prohibit third-party keyboards use the system keyboard.

FULL ACCESS AND DATA PROCESSING

Full Access lets the keyboard exchange recording commands, state and transcripts with VoiceType through a shared container. It does not upload text typed in the host app. Cloud transcription sends recorded audio, selected languages and vocabulary hints to VoiceType's server and OpenAI.

OTHER REVIEW PATHS

History preserves failed recordings with Retry and Delete. Credits are consumable App Store packs; Settings > Check purchases reconciles unfinished purchases. Settings > Delete account requests permanent deletion and revokes the stored Apple sign-in grant. Temporary revocation failures are shown so deletion can be retried.
